# R-015: タスク割り当て通知

リーダーがタスクを作成/更新して担当者を割り当てると、担当者に通知が届きます。担当者は「確認」ボタンでタスクの受領を確認します。すべての従業員がすべてのタスクとそのステータスを閲覧できます – システムはオープンで透明です。

## 変更点

### 1. データベース
- `notifications`テーブル – 通知
- `tasks.acknowledged_at` – 担当者が確認した時刻

**マイグレーション:** `supabase/migrations/20250213000000_task_notifications.sql`

```bash
supabase db push
# または
supabase migration up
```

### 2. バックエンド（Edge Function）
- `assignee.id`ありでタスクが作成/更新された場合 → 通知が作成される
- `GET /notifications` – 現在のユーザーの通知
- `PATCH /notifications/:id/read` – 既読としてマーク
- `POST /tasks/:id/acknowledge` – 担当者による確認

### 3. フロントエンド
- **TaskEditModal:** 担当者選択時に`{ id, name }`が送信される（`name`だけでなく）
- **NotificationsDropdown:** ヘッダーのベルボタン – 通知一覧
- **TaskCard:** 担当者向けの「確認」ボタン（自分に割り当てられた未確認のタスクのみ）

### 4. ステータスの透明性
- すべてのテナントメンバーがすべてのタスクを閲覧できる（GET /tasksはテナント単位）
- 各タスクに: 担当者、ステータス、確認済みかどうかが表示される

## 使い方

1. リーダーがタスクを作成または既存のタスクを編集する
2. 担当者を選択する（ドロップダウンから）
3. 保存後 – 担当者に通知が届く（ヘッダーのベルに）
4. 担当者がタスクカードの「確認」ボタンをクリックする
5. すべての従業員がタスクのステータスを閲覧できる
