# R-015: Уведомления о назначении задач

Когда руководитель создаёт/обновляет задачу и назначает ответственного, ответственному приходит уведомление. Ответственный подтверждает получение задачи кнопкой "Подтвердить". Все сотрудники видят все задачи и их статусы – система открытая и прозрачная.

## Изменения

### 1. База данных
- Таблица `notifications` – уведомления
- `tasks.acknowledged_at` – время, когда ответственный подтвердил получение

**Миграция:** `supabase/migrations/20250213000000_task_notifications.sql`

```bash
supabase db push
# или
supabase migration up
```

### 2. Бэкенд (Edge Function)
- При создании/обновлении задачи с `assignee.id` → создаётся уведомление
- `GET /notifications` – уведомления текущего пользователя
- `PATCH /notifications/:id/read` – отметить как прочитанное
- `POST /tasks/:id/acknowledge` – подтверждение ответственным

### 3. Фронтенд
- **TaskEditModal:** При выборе ответственного отправляется `{ id, name }` (не только `name`)
- **NotificationsDropdown:** Кнопка колокольчика в шапке – список уведомлений
- **TaskCard:** Кнопка "Подтвердить" для ответственного (только для назначенных ему и неподтверждённых задач)

### 4. Прозрачность статусов
- Все участники тенанта видят все задачи (GET /tasks по тенанту)
- В каждой задаче: ответственный, статус, подтверждено или нет

## Использование

1. Руководитель создаёт задачу или редактирует существующую
2. Выбирает ответственного (из выпадающего списка)
3. После сохранения – ответственному приходит уведомление (в колокольчик в шапке)
4. Ответственный нажимает кнопку "Подтвердить" на карточке задачи
5. Все сотрудники видят статус задачи
